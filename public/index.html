        It gets this with every decision, so your guidance can depend on it (“early on”, “while it's a few agents”, “once there are tests”). The concept is the project description in Settings.

        When an agent asks the humans a question, the deputy answers it with a house rule, an earlier decision, or one of the options the agent listed.

        Changes that touch a protected path need a person's approval to merge. The deputy can give it for the paths listed here, but never for a change with files outside its declared intent.

        A change's review brief flags it for a person when it touches files outside its declared intent, changes code without tests, or is new ground for its author.
